# Corrección interna anterior al depósito de resultados

El 28 de septiembre de 2026, durante la revisión editorial del análisis posterior al torneo, se detectó que `descriptive_tables` dividía dos veces por el número de rivales en las cuatro mezclas contrafactuales de actitudes: la media de una celda ya incorporaba ese denominador y el peso volvió a incluirlo. Este error afectaba exclusivamente a `descriptive_primary_scenario_0.counterfactual_mixes` del JSON local. La estadística H7, su valor p, los 16 escenarios, la ponderación por AST y los límites de exclusión se calculan por otras funciones y conservaron sus valores.

El JSON local retirado tenía SHA-256 `622447f2f729fbadfc5d1a983f3ff8a0fa04bd5a7ca87fa3df50358160508235`; el ZIP preliminar, SHA-256 `40547fcdd1ffd11e24949d13e5ff86b7e57ffe523694d3b61e66f6c319f4b271`. El JSON estuvo disponible en la carpeta local y se enlazó al usuario; no se depositó en OSF ni se remitió a una revista. La fórmula se corrigió a `peso_de_actitud / número_de_modelos × media_de_la_celda`, y una prueba sintética comprueba que las cuatro mezclas recuperan medias conocidas para cada actitud focal.

El análisis se ejecutó de nuevo sobre los 665 recibos. H7 conservó exactamente `0,005348991712007744` y p `1/10.001`; los resultados de las 16 máscaras, la sensibilidad AST y las cotas de exclusión también permanecieron iguales. Las tasas descriptivas corregidas de cooperación para las cuatro mezclas, promediadas sobre las 572 estrategias focales, son 49,28 % (equilibrada), 27,81 % (agresiva dominante), 60,18 % (cooperativa dominante) y 59,86 % (neutral dominante). El nuevo JSON tiene SHA-256 `06b1a9d18a799084dcc9f8b1b3d6f15ee2243ef938bf9b849024c16ee1236cf4`.
